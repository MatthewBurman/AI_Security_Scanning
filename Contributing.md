Contributing
We welcome contributions! Please see CONTRIBUTING.md for details.

**Areas for Contribution**
* Additional YARA rules for new malware campaigns
* Support for more IDE marketplaces (JetBrains, Eclipse, etc.)
* Enhanced obfuscation detection algorithms
* Behavioral analysis heuristics
* Performance optimizations
* Documentation and examples
* Adding New IOC Sources
* Create iocs/campaigns/new-campaign.json
* Follow the schema in iocs/schema.json
* Run npm run validate-iocs
* Submit PR with attribution
